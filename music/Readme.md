# Hướng dẫn thêm nhạc nền / How to add music

Bạn có thể thêm hoặc đổi bài hát theo các bước sau:

1. Copy file nhạc của bạn vào thư mục này (`music/`).
2. Đổi tên file nhạc đó thành `music.mp3` (ví dụ: `music/music.mp3`).
3. Hoặc nếu bạn muốn đặt tên khác (ví dụ: `bai-hat-yeu-thich.mp3`), bạn chỉ cần mở file `index.html`, tìm đến thẻ `<audio id="bg-music">` và sửa `src="music/music.mp3"` thành tên file của bạn.

Định dạng khuyên dùng: `.mp3` để tương thích tốt nhất trên tất cả trình duyệt (Chrome, Safari, iOS, Android, Edge).
